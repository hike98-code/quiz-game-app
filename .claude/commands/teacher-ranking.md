브라우저의 localStorage에서 퀴즈 데이터를 읽어 학생별 성적 순위표를 출력해줘.

$ARGUMENTS 형식: "$1" — 예: "speed", "category", "all"
- $1 = 모드 필터: speed | category | all | (생략 시 전체 모드 합산)

## 실행 순서

### Step 1 — 데이터 추출
MCP 브라우저 도구로 http://localhost:8080 에 접속한 뒤 아래 JavaScript를 실행한다:

```js
JSON.parse(localStorage.getItem('quiz_leaderboard') || '[]')
```

데이터가 없으면 "플레이 기록이 없습니다." 출력 후 종료.

### Step 2 — 모드 필터 적용

$1 인수에 따라 레코드를 필터링:
- `speed`    : record.mode === 'speed'
- `category` : record.mode === 'category'
- `all`      : record.mode === 'all'
- 생략        : 전체 레코드 사용

필터 적용 후 레코드가 0개면 "해당 모드의 기록이 없습니다." 출력 후 종료.

### Step 3 — 학생별 집계

name을 기준으로 그룹화하여 각 학생의 지표를 계산한다:

| 항목 | 계산 방법 |
|---|---|
| 최고 점수 | max(score) |
| 평균 점수 | avg(score), 소수점 1자리 |
| 평균 정답률 | avg(rate)%, 소수점 1자리 |
| 총 플레이 수 | 해당 학생 레코드 수 |
| 최대 콤보 | max(maxCombo) |
| 최근 플레이 | 가장 최근 date |
| 개선도 | 첫 게임 대비 마지막 게임 점수 차이 (플레이가 1회이면 '-') |

### Step 4 — 순위 정렬 및 출력

최고 점수 내림차순 → 평균 점수 내림차순으로 정렬.

```
══════════════════════════════════════
🏆 학생 성적 순위표
모드: [전체 / speed / category / all]
══════════════════════════════════════

| 순위 | 학생명 | 최고점수 | 평균점수 | 평균정답률 | 플레이 | 최대콤보 | 개선도 | 최근기록 |
|---|---|---|---|---|---|---|---|---|
| 🥇 1 | ... | ... | ... | ... | N회 | N | +N점↑ / -N점↓ | YYYY-MM-DD |
| 🥈 2 | ... |
| 🥉 3 | ... |
| 4  | ... |
...

[참여 학생 N명 / 총 플레이 N회]
```

### Step 5 — 주목할 학생

아래 항목을 각각 1명씩 별도 표시:
- **최고 점수 보유**: [이름] [점수]점
- **가장 성실한 플레이어** (플레이 수 1위): [이름] N회
- **가장 큰 성장** (개선도 1위): [이름] +N점 향상
- **정답률 1위**: [이름] N%

해당 기록이 없으면 "-" 표시.
