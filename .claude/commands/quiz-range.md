index.html 파일의 QUESTIONS 배열(또는 QUIZ_DATA 배열)에서 퀴즈 문제를 범위 단위로 검토해줘.

$ARGUMENTS 형식은 "$1 $2" — 예: "1 10"이면 1번~10번 문제를 대상으로 한다.
번호는 배열의 순서(1-based index)를 기준으로 한다.
$1만 있으면 그 문제 1개만, 인수가 없으면 전체 문제를 대상으로 해.

## 출력 내용

### 1. 문제 목록
각 문제를 아래 형식으로 한 줄씩 표시:
`[순번] ID | 카테고리 | 난이도 | 정답: [번호]번 — "선택지 텍스트"`

### 2. 난이도 분포
- easy / medium / hard 각 개수와 비율(%)을 표시
- 권장 비율(easy 30% / medium 50% / hard 20%)과 비교해
- 권장 범위를 벗어나면 ⚠️, 적정하면 ✅

### 3. 정답 분포
- 1번·2번·3번·4번 각 정답 개수와 비율(%)을 표시
- 특정 번호에 40% 이상 몰려 있으면 ⚠️ + 편중 경고, 고르면 ✅

### 4. 요약
- 검토 범위(N번~M번), 총 문제 수
- 난이도·정답 분포 각각 한 줄 판정
