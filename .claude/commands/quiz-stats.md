index.html 파일의 QUIZ_DATA 배열을 분석해 퀴즈 전체 데이터의 진행 현황과 통계를 수치화해줘.

$ARGUMENTS에 카테고리가 지정된 경우 해당 카테고리만, 없으면 전체를 분석해.
카테고리: history | science | geo | general

## 실행 순서

### Step 1 — 데이터 로드
index.html을 읽어 QUIZ_DATA 배열 전체(또는 지정 카테고리)를 추출한다.

### Step 2 — 전체 현황

아래 항목을 표로 출력한다:

| 항목 | 값 |
|---|---|
| 총 문제 수 | N개 |
| 카테고리 수 | N개 |
| 평균 문제 수/카테고리 | N.N개 |
| 카테고리별 문제 수 | history N / science N / geo N / general N |

### Step 3 — 난이도 분포 분석

#### 전체 난이도 분포
| 난이도 | 문제 수 | 비율 | 권장(30/50/20%) | 판정 |
|---|---|---|---|---|
| easy   | N | N% | 30% | ✅/⚠️ |
| medium | N | N% | 50% | ✅/⚠️ |
| hard   | N | N% | 20% | ✅/⚠️ |

권장 범위 기준: easy ±5%, medium ±5%, hard ±5%

#### 카테고리별 난이도 분포 (해당 카테고리만 분석 시 생략 가능)
각 카테고리별로 easy/medium/hard 개수와 비율을 표로 출력.
권장 범위를 벗어난 카테고리에 ⚠️ 표시.

### Step 4 — 정답 분포 분석

#### 전체 정답 번호 분포
| 정답 번호 | 문제 수 | 비율 | 판정 |
|---|---|---|---|
| 1번 (index 0) | N | N% | ✅/⚠️ |
| 2번 (index 1) | N | N% | ✅/⚠️ |
| 3번 (index 2) | N | N% | ✅/⚠️ |
| 4번 (index 3) | N | N% | ✅/⚠️ |

특정 번호에 40% 이상 몰리면 ⚠️ + 편중 경고.

#### 카테고리별 정답 분포 (4열 테이블)
각 카테고리별 1~4번 정답 개수를 표로 출력.

### Step 5 — 문제 ID 체계 현황

카테고리별로 사용 중인 ID 목록과 빈 번호(gap)를 표시한다:
- history  : WH-001 ~ WH-NNN (총 N개, gap: 없음/있으면 번호 명시)
- science  : SC-001 ~ SC-NNN
- geo      : GE-001 ~ GE-NNN
- general  : GN-001 ~ GN-NNN

### Step 6 — 종합 판정 및 개선 제안

아래 항목을 한 줄씩 출력:
- 전체 문제 수 충분성 (40문제 기준, 카테고리당 10문제 권장)
- 난이도 균형 판정 (✅ 균형 / ⚠️ 조정 필요 — 어떤 난이도를 추가/제거할지)
- 정답 번호 균형 판정 (✅ 균형 / ⚠️ 조정 필요 — 어떤 번호가 과다/부족한지)
- 추가 권장 문제 수 및 카테고리 제안
