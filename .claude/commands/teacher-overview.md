브라우저의 localStorage에서 퀴즈 전체 플레이 데이터를 읽어 학급 전체 현황을 요약해줘.

## 실행 순서

### Step 1 — 데이터 추출
MCP 브라우저 도구로 http://localhost:8080 에 접속한 뒤 아래 JavaScript를 실행해 데이터를 읽는다:

```js
JSON.parse(localStorage.getItem('quiz_leaderboard') || '[]')
```

데이터가 없으면 "플레이 기록이 없습니다." 출력 후 종료.

### Step 2 — 전체 현황 집계

아래 수치를 계산한다:
- 총 플레이 수 (전체 레코드 수)
- 참여 학생 수 (name 기준 중복 제거)
- 전체 평균 점수
- 전체 평균 정답률
- 최고 점수 (학생명 포함)
- 최고 정답률 (학생명 포함)

### Step 3 — 모드별 현황

| 모드 | 플레이 수 | 평균 점수 | 평균 정답률 | 참여 학생 수 |
|---|---|---|---|---|
| 전체도전 (all) | N | N점 | N% | N명 |
| 카테고리별 (category) | N | N점 | N% | N명 |
| 스피드퀴즈 (speed) | N | N점 | N% | N명 |

### Step 4 — 점수 분포

전체 플레이를 점수 구간별로 분류:
- 600점 이상 (S등급): N회 (N%)
- 400~599점 (A등급): N회 (N%)
- 250~399점 (B등급): N회 (N%)
- 100~249점 (C등급): N회 (N%)
- 100점 미만 (D등급): N회 (N%)

### Step 5 — 날짜별 활동 추이

날짜(date)별 플레이 수를 오름차순으로 표시:
```
YYYY-MM-DD : N회
```
가장 활발했던 날짜 1위를 별도 강조.

### Step 6 — 출력

아래 형식으로 출력한다:

```
══════════════════════════════════════
📊 학급 전체 현황 요약
기준: [오늘 날짜]
══════════════════════════════════════

👥 참여 학생: N명
🎮 총 플레이: N회  (1인 평균 N.N회)
⭐ 전체 평균 점수: N점
🎯 전체 평균 정답률: N%

🏆 최고 점수  : N점 — [학생명]
🎯 최고 정답률: N%  — [학생명]

[모드별 현황 테이블]

[점수 분포]

[날짜별 활동 추이]
══════════════════════════════════════
```
