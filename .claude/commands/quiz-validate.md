index.html 파일의 QUIZ_DATA 배열에서 퀴즈 문제(question 필드)를 분석해줘.

$ARGUMENTS에 카테고리가 지정된 경우 해당 카테고리의 문제만 검증하고,
지정되지 않은 경우 전체 문제를 검증해줘.
카테고리는 QUIZ_DATA의 category 필드와 비교하면 돼 (예: history, science, geo, general).

다음 최상급·절대적 표현이 포함된 문제를 찾아서 목록으로 보여줘:
- 가장, 최초, 최대, 최소, 최장, 최단, 최고, 최저, 유일, 처음, 먼저

출력 형식:
1. 문제 ID와 question 텍스트를 함께 표시
2. 어떤 표현이 포함됐는지 명시
3. explanation 또는 hint에 기준(면적, 연도, 범위 등)이 명시되어 있는지 확인
4. 기준이 불명확하면 ⚠️ + 어떤 기준을 명시해야 하는지 제안, 명확하면 ✅ 표시

마지막에 검증 대상 문제 수 대비 해당 문제 수 요약도 보여줘.
