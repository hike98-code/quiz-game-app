브라우저의 localStorage에서 특정 학생의 퀴즈 기록을 읽어 상세 성적을 분석해줘.

$ARGUMENTS 형식: "$1" — 예: "hike98", "홍길동"
- $1 = 조회할 학생 이름 (정확히 일치하는 name 필드 기준)
- 인수가 없으면 오류 메시지를 출력하고 중단:
  "오류: 학생 이름을 입력해주세요. 예) /teacher-student 홍길동"

## 실행 순서

### Step 1 — 데이터 추출
MCP 브라우저 도구로 http://localhost:8080 에 접속한 뒤 아래 JavaScript를 실행한다:

```js
JSON.parse(localStorage.getItem('quiz_leaderboard') || '[]')
```

데이터가 없으면 "플레이 기록이 없습니다." 출력 후 종료.

### Step 2 — 학생 필터링

name === $1 인 레코드만 추출. 대소문자 구분 없이 비교.
레코드가 없으면 "학생 '$1'의 기록을 찾을 수 없습니다." 출력 후 종료.
2명 이상 이름이 같으면 동일 인물로 합산 처리.

### Step 3 — 종합 성적 요약

해당 학생의 모든 레코드를 기반으로 집계:

| 항목 | 값 |
|---|---|
| 총 플레이 수 | N회 |
| 최고 점수 | N점 |
| 평균 점수 | N.N점 |
| 평균 정답률 | N.N% |
| 최대 콤보 | N |
| 첫 플레이 | YYYY-MM-DD |
| 최근 플레이 | YYYY-MM-DD |
| 총 활동 기간 | N일 |
| 점수 개선도 | 첫 게임 → 마지막 게임 (차이: ±N점) |

### Step 4 — 게임 이력 타임라인

timestamp 오름차순(과거→최근)으로 전체 기록을 출력:

```
[N회차] YYYY-MM-DD | 모드: [모드명] | 카테고리: [카테고리/all] | N점 | 정답률 N% | 콤보 N
```

점수가 직전 게임 대비 올랐으면 ↑, 내렸으면 ↓ 표시.

### Step 5 — 카테고리별 성과

카테고리 모드 기록이 있는 경우 카테고리별 집계:

| 카테고리 | 플레이 수 | 최고 점수 | 평균 정답률 | 성취도 |
|---|---|---|---|---|
| history | N | N점 | N% | 우수/보통/미흡 |

성취도 기준: 정답률 70%↑ = 우수 / 40%~69% = 보통 / 40%↓ = 미흡

카테고리 모드 기록이 없으면 해당 섹션 생략.

### Step 6 — 성장 추이 분석

플레이가 2회 이상인 경우:
- 전반부(초반 절반) 평균 점수 vs 후반부(후반 절반) 평균 점수 비교
- 개선 추세: 상승 중 ↗ / 하락 중 ↘ / 유지 →

### Step 7 — 교사 코멘트 생성

아래 기준으로 맞춤 피드백 1~3문장을 자동 생성한다:
- 정답률 70% 이상: 성취 인정 + 더 어려운 도전 권유
- 정답률 40~69%: 약한 카테고리 집중 학습 권유
- 정답률 40% 미만: 기초 강화 권유 + 쉬운 모드 추천
- 플레이 수 5회 이상: 성실함 칭찬

### Step 8 — 출력

```
══════════════════════════════════════
👤 학생 상세 성적: [$1]
══════════════════════════════════════

[종합 성적 테이블]

── 게임 이력 ────────────────────────
[타임라인]

── 카테고리별 성과 ──────────────────
[카테고리 테이블 또는 "카테고리 모드 기록 없음"]

── 성장 추이 ────────────────────────
[추이 분석 또는 "기록 1회 — 추이 분석 불가"]

── 교사 코멘트 ──────────────────────
[자동 생성 피드백]

══════════════════════════════════════
```
