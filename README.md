# 🧠 상식 퀴즈 게임

연령별 맞춤 프로필과 다양한 게임 모드를 갖춘 한국어 상식 퀴즈 웹앱입니다.  
외부 라이브러리 없이 Vanilla HTML/CSS/JS 단일 파일로 구현되어 있습니다.

## 데모 실행

```bash
python -m http.server 8080
# → 브라우저에서 http://localhost:8080 접속
```

또는 `index.html`을 브라우저에서 직접 열어도 됩니다.

## 주요 기능

### 연령 프로필
| 프로필 | 대상 | 문제 수 | 특이사항 |
|---|---|---|---|
| 미취학아동 | 7세 이하 | 20문제 | TTS 자동 음성 읽기 |
| 초등학생 | 8~13세 | 40문제 | 태권도 카테고리 포함 |
| 중학생 | 13~15세 | 20문제 | — |
| 일반/성인 | 청소년·성인 | 44문제 | — |

### 게임 모드
- **전체 도전** — 프로필에 맞는 전체 문제를 순서 셔플 후 출제
- **카테고리별** — 세계사·과학·지리·일반상식 중 선택하여 집중 학습
- **스피드 퀴즈** — 20문제, 문항당 15초 제한

### 점수 시스템
- 기본 10점 + 난이도 배수 (easy×1 / medium×1.5 / hard×2)
- 보너스: 빠른 응답(10초 미만 +3), 힌트 미사용 +2, 콤보(3연속 +2, 5연속 +5, 10연속 +20)
- 등급: S(600점↑) / A(400점↑) / B(250점↑) / C(100점↑) / D

### 기타
- 리더보드 (기간·모드 필터)
- 개인 통계 대시보드 (게임 이력, 카테고리별 성취도)
- 선생님 모드 — 학생 전체 현황·순위·성취 분석 리포트 생성

## 문제 구성

총 **124문제** (easy 30% / medium 50% / hard 20% 권장 비율)

| 카테고리 | 대상 |
|---|---|
| 세계사 (`history`) | 일반·초등·중학 |
| 과학 (`science`) | 일반·초등·중학 |
| 지리 (`geo`) | 일반·초등·중학 |
| 일반상식 (`general`) | 일반·초등·중학 |
| 태권도 (`taekwondo`) | 초등 전용 |

## 기술 스택

- HTML / CSS / JavaScript (ES6+)
- Web Speech API (TTS, 미취학아동 전용)
- localStorage (게임 이력·통계·리더보드)
- Google Fonts — Noto Sans KR

## 파일 구조

```
index.html          # 앱 전체 (HTML + CSS + JS 단일 파일)
CLAUDE.md           # Claude Code 개발 가이드
.claude/commands/   # 커스텀 슬래시 명령어
  quiz-add.md       # 문제 추가
  quiz-stats.md     # 통계 분석
  quiz-daily.md     # 일일 유지보수 루틴
  teacher-mode.md   # 선생님 모드 종합 리포트
  ...
```
