# 🧠 상식 퀴즈 게임

연령별 맞춤 프로필과 다양한 게임 모드를 갖춘 한국어 상식 퀴즈 웹앱입니다.  
외부 라이브러리 없이 Vanilla HTML/CSS/JS 단일 파일(`index.html`)로 구현되어 있습니다.

## 데모 실행

```bash
python -m http.server 8765
# → 브라우저에서 http://localhost:8765 접속
```

또는 `index.html`을 브라우저에서 직접 열어도 됩니다(`file://`). 기록은 브라우저 localStorage에 저장되며, `file://`과 `localhost`의 기록은 서로 따로 저장됩니다.

## 주요 기능

### 연령 프로필
| 프로필 | 대상 | 문제 수 | 카테고리 | 특이사항 |
|---|---|---|---|---|
| 미취학아동 | 7세 이하 | 130문제 | 일반상식·과학·지리, 이웃집 토토로, 생물, 디저트, 공룡, 탈것 | TTS 음성 읽기, 보기 이미지 |
| 초등학생 | 8~13세 | 40문제 | 세계사·과학·지리·일반상식, 태권도 | — |
| 중학생 | 13~15세 | 20문제 | 세계사·과학·지리·일반상식 | — |
| 일반/성인 | 청소년·성인 | 44문제 | 세계사·과학·지리·일반상식 | — |

### 게임 모드
- **전체 도전** — 프로필에 맞는 전체 문제를 순서 셔플 후 출제
- **카테고리별** — 프로필에 있는 카테고리 중 하나를 골라 집중 학습 (문제가 없는 카테고리는 자동으로 숨김)
- **스피드 퀴즈** — 20문제, 문항당 15초 제한

### 미취학아동 전용
- **TTS 음성 안내** (Web Speech API)
  - 문제와 보기를 자동으로 읽어 주고, 읽는 보기를 화면에서 강조
  - 보기 번호는 '일번~사번'으로 읽음
  - 힌트를 누르면 힌트를 읽어 줌
  - 답을 고르면 '정답이에요!' 또는 '아쉬워요. 정답은 …'과 함께 해설을 읽어 줌
- **보기 이미지** — 보기 오른쪽에 내용을 나타내는 그림 표시
  - 색깔 보기는 색 동그라미, 개수 보기는 점 그림, 그 밖에는 이모지
  - 공룡 카테고리는 직접 그린 공룡 SVG 그림 15종
  - 보기 내용만 그림으로 옮기며, 문제의 정답을 드러내는 그림은 쓰지 않음

### 점수 시스템
- 기본 10점 + 난이도 배수 (easy×1 / medium×1.5 / hard×2)
- 보너스: 빠른 응답(10초 미만 +3), 힌트 미사용 +2, 콤보(3연속 +2, 5연속 +5, 10연속 +20)
- 등급: 40문제 기준으로 환산해 S(600점↑) / A(400점↑) / B(250점↑) / C(100점↑) / D

### 기록·통계
- **자동 저장** — 결과 화면이 뜨면 게임 이력과 통계가 자동 저장됨
- **순위 등록** — 닉네임을 입력하고 '등록'을 누르면 리더보드에 추가됨
- **리더보드** — 기간(전체·이번 주·오늘)·모드 필터, 상위 10건 표시, '내 최고기록' 카드
- **내 통계** — 종합 요약, 최고 기록, 카테고리별 정답률(모든 카테고리), 모드별 통계, 최근 10게임
- **선생님 모드** — 학생 전체 현황·순위·성취 분석 리포트 생성 (Claude Code 슬래시 명령어)

| 이웃집 토토로 (`totoro`) | 미취학 전용 | 30 |
| 생물 (`living`) — 동물·곤충·식물 | 미취학 전용 | 20 |

정답 번호(①~④)는 프로필마다 고르게 나눠 출제됩니다.

## 테스트

[Playwright](https://playwright.dev)로 화면별 E2E 테스트를 작성했습니다. 뷰포트는 모바일 크기(390×844)로 고정되어 있습니다.

```bash
npm install          # 최초 1회
npx playwright test  # 전체 실행 (로컬 서버 자동 기동)
npm run test:ui      # Playwright UI 모드
```

- `tests/ai-generated/` — 테스트 계획서(`specs/quiz-app-test-plan.md`)를 기반으로 화면별로 나눈 스위트 (90 TC)
- `tests/quiz.spec.ts` — 초기 단일 파일 스위트 (10 TC)
- 미취학 TTS 테스트는 `speechSynthesis`를 모킹해 읽는 문장을 검증

## 기술 스택

- HTML / CSS / JavaScript (ES6+), 단일 파일
- Web Speech API (TTS, 미취학아동 전용)
- localStorage (게임 이력·통계·리더보드)
- Google Fonts — Noto Sans KR
- Playwright (E2E 테스트)
